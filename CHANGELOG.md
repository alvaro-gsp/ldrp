# Changelog

## 1.0.0 (2026-11-06)

- Initial release
- Local file sharing over Wi-Fi with QR code access
- PIN-protected sessions (rotates on each launch)
- Real-time file sync via Server-Sent Events
- Auto Wi-Fi IP detection (skips VPN and virtual adapters)
- Windows firewall rule auto-creation (scoped to Python executable)
- Responsive UI: table view on desktop, compact list on mobile
- Drag-and-drop and button upload
- Download and delete from any connected device
- Pure Python, zero external dependencies
